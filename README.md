## Request a Tutorial

Missing something? Two ways to ask:

1. [**Request a new tutorial**](https://github.com/ravsau/ai-tutorials/issues/new?labels=tutorial-request&title=Tutorial%20request%3A%20) — a tool, model, or workflow you want covered.
2. [**Request the code for an existing video**](https://github.com/ravsau/ai-tutorials/issues/new?labels=code-request&title=Code%20request%3A%20) — name the video and what you need.

Please include:

- What you want to build or fix.
- Your hardware or cloud setup (for example: M3 Mac 36 GB, or AWS).
- What you already tried.

Requests with the most 👍 get made first.
